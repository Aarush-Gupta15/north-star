Install North Star in under a minute

The extension is free and open-source. Until it's on the Chrome Web Store, you can load it directly — here's how.

⬇ Download North Star (v1.5.1) See the steps
Chrome / Edge / Brave · Manifest V3 · ~45 KB · 100% local — nothing ever leaves your browser
1

Download & unzip

Download the package above and unzip it. You'll get a folder called north-star-personal.

2

Open the extensions page

In Chrome, go to chrome://extensions (paste it into the address bar).

3

Turn on Developer mode

Flip the Developer mode toggle in the top-right corner.

4

Load unpacked

Click Load unpacked and select the unzipped north-star-personal folder.

5

Pin it & start typing

Click the puzzle-piece icon and pin North Star. That's it — it now watches every text box you type into.

Try it right away

Open ChatGPT, Gemini, or Gmail and type a test value into the message box:

Card 4111 1111 1111 1111  ·  Aadhaar 2341 2345 6783  ·  a password like 48#efhljhdfw

You'll see it underlined instantly, with a badge to review and one click to redact. (Use fake values only — never your real data when testing.)

Is this safe to load unpacked? Yes. North Star runs entirely on your device — there's no server, no account, and no tracking. It's open-source, so you can read every line before installing. See the Privacy Policy.
